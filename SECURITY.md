# Security Policy

## Supported versions

Gmad 2.1.x receives security fixes. Older builds are not supported.

## Reporting a vulnerability

Contact boo271 on Discord. Send details privately instead of opening a public issue, especially if the report includes personal data, file contents, or steps that could put other users at risk.

Include the Gmad version, Android version, and device model where possible. You will get a reply as soon as possible.
